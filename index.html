Application architecture

Three layers. One connected application.

01 / PRESENTATION

Web & routing

Nginx serves this portal and forwards API requests to the Python backend within the ECS task.

Nginx · HTTP · Reverse proxy
02 / APPLICATION

Backend services

Gunicorn serves Flask routes for health checks, authenticated user queries, and validated image uploads.

Gunicorn · Flask · Python
03 / DATA

Database & storage

MySQL on Amazon RDS stores user records. Amazon S3 stores uploaded images using generated object names.

Amazon RDS · Amazon S3

Engineering practices

More than a running container.

The project combines application development with infrastructure, security controls, repeatable checks, and operational evidence.

Project scope

  • Non-root backend with a read-only ECS root filesystem.
  • Bearer-token authentication and image upload validation.
  • GitHub Actions security tests and container checks.
  • Terraform VPC configuration and validation.
  • Documented integration tests and resource cleanup.
